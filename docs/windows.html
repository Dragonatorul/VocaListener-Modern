VocaListener Modern

Windows user guide · English by default · Japanese available

Install · Convert a recording · Your files · Troubleshooting · Update or uninstall

Install with one download

  1. Visit the latest release and download VocaListener-Modern-<version>-Windows-x64-Setup.exe from Assets. GitHub's “Source code” archives are for developers.
  2. Run the file. Choose Just Me and keep the suggested installation folder. The installer is unsigned; Windows may display an unknown-publisher prompt. Check that the file came from this project's release page before choosing to run it.
  3. Open VocaListener Modern from the Start menu. This guide is available as User Guide beside it, and from Get Help or Tutorial in the app.

Requires Windows 11 x64 (Intel or AMD), a CPU, and enough disk space for the bundled runtime and working audio. Allow several GB of free space during installation. No separate software installation, GPU, command prompt, terminal, model download, or internet connection is required after downloading the installer. All processing is local. Windows on ARM is not a tested target.

Convert a recording

  1. Start with a short, clear recording of one unaccompanied singer. WAV is recommended; FLAC and MP3 are also useful. Background instruments, effects, and long recordings can make alignment less accurate and processing slower.
  2. Leave English selected, or choose Japanese. Both language models and dictionaries are included. Japanese accepts UTF-8 Japanese text; use the same written words as the recording.
  3. Click Choose Audio File, then select your recording.
  4. Type the exact lyrics into the text box or choose a UTF-8 .txt lyrics file. A selected text file takes priority over typed text.
  5. Click Next, then Start Processing. The five steps extract pitch, align speech sounds with the lyrics, read the alignment, map phonemes, and write the project. The first pitch extraction can take longer while its local cache is prepared.
  6. After completion, click Save Output File and choose a location for your .svp.
  7. Open that file in Synthesizer V, select your own English- or Japanese-capable voice, and review the timing, pronunciation, and pitch. The source recording is not embedded in the project.

The converter includes everything needed to create the project. Synthesizer V and voice databases are separate products used to edit or render it. The export currently uses placeholder “la” note lyrics with explicit phonemes; it does not restore the original written lyrics to each note. MFA models are trained on speech, so singing may need manual edits. Japanese long consonants and devoiced vowels are approximate mappings. Vocaloid export is disabled because it is not implemented. The Record button is a placeholder; select an existing recording.

Stop finishes the current step before stopping. Click a step indicator to resume from that step only when its earlier intermediate files still exist. Clear Tmp removes intermediate output while retaining input and profile. Save the final project elsewhere before starting another conversion.

Where your files are stored

By default the program is installed under %LOCALAPPDATA%\Programs\VocaListener-Modern. It keeps working files separately under %LOCALAPPDATA%\VocaListener-Modern\data. Paste either path into File Explorer's address bar.

  • tmp\input: copies of the selected recording and lyrics. Selecting another recording replaces the prior input pair.
  • tmp\output.svp: latest generated project; use Save Output File to keep your own copy.
  • res\english\synthV.txt and res\japanese\synthV.txt: editable phoneme mappings. Each row is source phoneme | SynthV phoneme | English (or Japanese). Edits are preserved when the app restarts.
  • application.log, tmp, and mfa: startup and processing diagnostics.

The installed app\third-party directory contains component notices, model licenses, source metadata, and package inventory. Application source is installed in app\src.

Troubleshooting

  • App does not open: check application.log in the data folder above. Reinstall from the official release asset if the runtime is incomplete.
  • Alignment fails: check that language and lyrics match the audio, try a shorter clean WAV, and read the processing log. Do not download extra models; both supported languages are already included.
  • Missing phoneme warning: the app adds unmapped symbols to your editable dictionary. Complete those rows, then resume from Remap Phones. To restore a bundled mapping, close the app, rename the edited mapping file, and reopen it.
  • Incorrect sound in Synthesizer V: choose a voice that supports the project's language and review its explicit phonemes. Japanese mapping quality needs listening checks with your chosen voice.

Check the release notes for fixes and known issues. When requesting support, include the release version, language, failing step, and relevant log excerpt. Logs can include file paths and lyrics; review them before sharing. Internet access is only needed to visit support or download releases.

Update or uninstall

Save output projects, close the app, and uninstall the previous version through Windows Settings → Apps → Installed apps → VocaListener Modern before installing a new release. The installer requires an empty destination. Your data directory and saved projects are retained. Remove the data directory yourself to erase recordings, lyrics, cache, and custom mappings too.

Automated release checks use Windows Server runners, including installation into a path with spaces and conversion from a user path containing Japanese characters. Actual pronunciation quality and physical Windows 11 desktop behavior should be checked with your recordings.
